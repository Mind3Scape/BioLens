# BioLens

Архив анализов и медицинских документов. Кидаешь скриншот или снимаешь бланк камерой — приложение само читает дату, лабораторию и показатели, складывает их в линии по годам и отвечает на вопросы. Плюс «Тарелка»: фото еды → калории, БЖУ, клетчатка, насыщенные жиры и связь с целью из анализов.

## Как запустить на компьютере

```bash
python3 -m http.server 8801
```

Открыть [http://localhost:8801](http://localhost:8801). Камера работает только на `localhost` или по `https` — так устроены браузеры.

## Как попасть на телефон

Нужен `https`, иначе не будет камеры. Самый простой путь — GitHub Pages: залить эту папку в репозиторий, включить Pages, открыть ссылку на телефоне и «Добавить на экран «Домой»». Ключ OpenRouter в коде не лежит — он вводится в приложении и хранится в браузере устройства, поэтому публичный репозиторий безопасен.

## Telegram

Приложение открывается как Mini App внутри бота: кнопка меню рядом с полем ввода. Внутри Телеграма оно берёт его тему, использует системную кнопку «Назад», даёт тактильный отклик и хранит **ключ OpenRouter и выбор модели в облаке Телеграма** — они переезжают на другое устройство сами. Сами анализы туда не уходят: они лежат в памяти устройства.

Если Телеграм не даёт доступ к видеопотоку, сканер сам переключается на системную камеру — снимок делается штатным приложением камеры.

## PDF

Модели читают снимки, а не файлы, поэтому PDF разбирается **на устройстве**: `js/pdfdoc.js` рендерит страницы через pdf.js (лежит в `js/vendor/`, ничего не тянется из сети) и дальше они идут тем же путём, что и фотографии бланков. Ограничения: до 12 страниц на файл, ширина рендера 1400px. Одна выписка остаётся **одним документом** — результаты страниц сливаются: дата, лаборатория и название берутся с первой страницы, где они есть, показатели складываются с защитой от повторов.

Сбой на одной странице не хоронит документ: он сохраняется с пометкой, какие страницы прочитать не вышло. При ответе 429 (частая история у бесплатных моделей) запрос повторяется дважды с паузой, между страницами держится пауза 400 мс.

## Где живут данные

Три уровня, от быстрого к надёжному:

1. **Устройство** — IndexedDB. Всё работает мгновенно и офлайн, но живёт ровно до чистки кэша Телеграма.
2. **Облако Телеграма** (`CloudStorage`) — автоматическая копия «скелета»: числа, даты, лаборатории, еда, профиль. Пишется раз в 5 секунд после изменений, режется на куски по 3800 символов. Переезжает на любое устройство с тем же аккаунтом: при первом запуске на новом телефоне приложение само предложит вернуть архив. **Снимки туда не помещаются** — лимит около 4 МБ на пользователя.
3. **Файл** — полная копия вместе с оригиналами бланков (base64), руками из настроек. Восстановление — оттуда же.

Отдельного логина нет: внутри Телеграма пользователь уже вошёл, приложение читает его аккаунт из `initDataUnsafe` и держит копию в его личном облаке. Проверка подписи `initData` здесь не нужна — сервера нет, никакие чужие данные не отдаются.

## Что нужно для работы ИИ

1. Ключ на [openrouter.ai](https://openrouter.ai) → Keys.
2. В приложении: аватар в шапке → «Ключ OpenRouter» → вставить → «Проверить».
3. Там же выбрать модель:
   - **Для снимков** — обязательно из тех, что умеют картинки (значок глаза). Начать можно с `google/gemini-2.5-flash` — дёшево и уверенно читает таблицы.
   - **Для текстов** — любая, ей достаются вопросы и формулировки.
4. «Переразобрать всё заново» — прогоняет весь архив через выбранную модель, если захочется сменить её на более сильную.

## Как устроено внутри

| Файл | За что отвечает |
|---|---|
| `js/db.js` | IndexedDB: документы, замеры, еда, картинки; настройки в localStorage; выгрузка и полное удаление |
| `js/markers.js` | Словарь показателей: синонимы названий, пересчёт единиц, типовые нормы по полу |
| `js/store.js` | Документы → замеры → линии; сводка, «что пересдать», цель по питанию, контекст для ИИ |
| `js/openrouter.js` | Запросы к OpenRouter: список моделей, разбор бланка, разбор тарелки, вопросы; правила языка |
| `js/views.js` | Экраны |
| `js/ui.js` | График со ступенчатым коридором нормы, спарклайны, шторки, тосты |
| `js/scan.js` | Сканер-камера: рамка, оценка резкости, много кадров подряд |
| `js/demo.js` | Демонстрационный архив на 12 документов — посмотреть до ввода ключа |

## Принципы, которые нельзя нарушать

- Оригинал снимка хранится всегда, распознанное число можно поправить.
- Единицы пересчитываются, но исходное значение из бланка видно в списке замеров.
- Коридор нормы берётся из бланка; если его там нет — типовой, и это подписано.
- Неуверенно распознанное число помечается пунктиром и не попадает в страницу для врача.
- Диагнозы не ставятся, лечение не назначается.
- Данные лежат на устройстве. Наружу уходит только то, что отправляется в модель при разборе и вопросах — об этом честно написано в настройках.
